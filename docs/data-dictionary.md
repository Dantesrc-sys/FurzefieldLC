## System constants

Defined in `com.flc.config.AppConfig`. These values are referenced throughout
the business logic layer and enforced at the model level.

| Constant | Value | Used in |
|---|---|---|
| `MAX_LESSON_CAPACITY` | 4 | `Lesson.addMember()`, `Lesson.isFull()`, `Lesson.getAvailableSpaces()` |
| `RATING_MIN` | 1 | `Review` constructor, `Review.setRating()`, `ReviewController.addReview()` |
| `RATING_MAX` | 5 | `Review` constructor, `Review.setRating()`, `ReviewController.addReview()` |
| `LESSONS_PER_DAY` | 3 | Defines the timetable structure: Morning, Afternoon, Evening |

## Entities

### Member

Represents a registered member of Furzefield Leisure Centre.  
Java class: `com.flc.model.Member`

| Field | Type | Mutability | Constraints | Example |
|---|---|---|---|---|
| `memberId` | `String` | Immutable | Format: `M` followed by 3 zero-padded digits. Unique across all members. | `M001` |
| `name` | `String` | Mutable | Letters, spaces, hyphens, and apostrophes only. Minimum 2 characters, maximum 50 characters. Whitespace trimmed. | `Alice Carter` |
| `phone` | `String` | Mutable | 10 to 15 digits. Optional leading `+`. Spaces removed before validation. | `07700900001` |

**Validation source:** `com.flc.validation.ValidationUtil.validateName()` and `validatePhone()`  
**Uniqueness:** `memberId` enforced by `DataStore.addMember()`. Name uniqueness enforced by `MemberController.addMember()`.

### Lesson

Represents a single scheduled group exercise session.  
Java class: `com.flc.model.Lesson`

| Field | Type | Mutability | Constraints | Example |
|---|---|---|---|---|
| `lessonId` | `String` | Immutable | Format: `L` + 2-digit week + day abbreviation + slot number. Unique across all lessons. | `L01SAT1` |
| `exerciseType` | `ExerciseType` | Immutable | Must reference a valid `ExerciseType`. Cannot be null. | `E001 (Yoga)` |
| `day` | `Day` | Immutable | Must be `SATURDAY` or `SUNDAY`. | `SATURDAY` |
| `timeSlot` | `TimeSlot` | Immutable | Must be `MORNING`, `AFTERNOON`, or `EVENING`. | `MORNING` |
| `weekNumber` | `int` | Immutable | Range: 1 to 8. Represents the weekend number within the season. | `1` |
| `members` | `List<Member>` | Mutable | Maximum size: `MAX_LESSON_CAPACITY` (4). No duplicate members. | `[M001, M002, M003]` |

**Derived values:**

| Value | Calculation | Description |
|---|---|---|
| `price` | Delegated to `exerciseType.getPrice()` | Cost per member per session |
| `enrolledCount` | `members.size()` | Number of currently enrolled members |
| `availableSpaces` | `MAX_LESSON_CAPACITY - members.size()` | Remaining capacity |
| `isFull` | `members.size() >= MAX_LESSON_CAPACITY` | True when no spaces remain |
| `totalIncome` | `members.size() * exerciseType.getPrice()` | Total income generated by this lesson |

**Timetable pattern across the 8-weekend season:**

| Day | Slot 1 - Morning | Slot 2 - Afternoon | Slot 3 - Evening |
|---|---|---|---|
| Saturday | Yoga (E001) | Zumba (E002) | Box Fit (E004) |
| Sunday | Aquacise (E003) | Body Blitz (E005) | Yoga (E001) |

### Booking

Represents a confirmed booking linking one member to one lesson.  
Java class: `com.flc.model.Booking`

| Field | Type | Mutability | Constraints | Example |
|---|---|---|---|---|
| `bookingId` | `String` | Immutable | Format: `B` followed by 3 zero-padded digits. Unique across all bookings. | `B001` |
| `member` | `Member` | Immutable | Must reference a valid `Member`. Cannot be null. | `M001 (Alice Carter)` |
| `lesson` | `Lesson` | Mutable | Must reference a valid `Lesson`. Can be changed via `changeLesson()`. Cannot be null. | `L01SAT1` |

**Business rules enforced before a booking is created:**

- The target lesson must not be full (enrolled count less than `MAX_LESSON_CAPACITY`)
- The member must not already be enrolled in the same lesson
- The member must not have an existing booking on the same week, day, and time slot (time conflict check)

**Business rules enforced before a booking is changed:**

- The new lesson must not be full
- The new lesson must not be the same as the current lesson
- The member must not have a time conflict with the new lesson (the old booking slot is temporarily released before checking)

### Review

Represents a star-rated review submitted by a member for a lesson they attended.  
Java class: `com.flc.model.Review`

| Field | Type | Mutability | Constraints | Example |
|---|---|---|---|---|
| `reviewId` | `String` | Immutable | Format: `R` followed by 3 zero-padded digits. Unique across all reviews. | `R001` |
| `member` | `Member` | Immutable | Must reference a valid `Member`. Cannot be null. | `M001 (Alice Carter)` |
| `lesson` | `Lesson` | Immutable | Must reference a valid `Lesson`. Cannot be null. | `L01SAT1` |
| `rating` | `int` | Mutable | Range: `RATING_MIN` (1) to `RATING_MAX` (5) inclusive. | `5` |
| `comment` | `String` | Mutable | Optional. Null values are converted to an empty string. Leading and trailing whitespace is trimmed. | `Fantastic yoga session!` |

**Rating labels:**

| Rating | Label |
|---|---|
| 1 | Very Dissatisfied |
| 2 | Dissatisfied |
| 3 | Ok |
| 4 | Satisfied |
| 5 | Very Satisfied |

**Business rules enforced before a review is submitted:**

- The member must be enrolled in the lesson they are reviewing
- Each member may submit at most one review per lesson

## ID format reference

All identifiers are generated sequentially and never reused within a session.

| Entity | Format | Example | Generated by |
|---|---|---|---|
| Member | `M` + 3-digit zero-padded integer | `M001`, `M010` | `MemberController.generateMemberId()` |
| ExerciseType | `E` + 3-digit zero-padded integer | `E001`, `E005` | Defined in `SampleData` |
| Lesson | `L` + 2-digit week + day code + slot number | `L01SAT1`, `L08SUN3` | Defined in `SampleData` |
| Booking | `B` + 3-digit zero-padded integer | `B001`, `B050` | `BookingController.generateBookingId()` |
| Review | `R` + 3-digit zero-padded integer | `R001`, `R022` | `ReviewController.generateReviewId()` |

**Lesson ID decoder:**

| Segment | Meaning | Values |
|---|---|---|
| `L` | Literal prefix | Fixed |
| `01` to `08` | Weekend number, zero-padded | 01 to 08 |
| `SAT` or `SUN` | Day of the week | SAT or SUN |
| `1`, `2`, or `3` | Time slot number | 1 = Morning, 2 = Afternoon, 3 = Evening |

Example: `L03SUN2` = Week 3, Sunday, Afternoon (Body Blitz, £13.00)
